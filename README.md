# Keofi

## Overview

Keofi is a responsive coffee shop website designed to showcase a modern café experience online. It provides visitors with an elegant menu display, information about the café, and easy access to ordering details using clean HTML, CSS, and JavaScript.

## Features

- Responsive design for desktop and mobile devices
- Menu showcase with coffee and beverage sections
- Smooth navigation and visual layout
- Contact and location information

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Installation

1. Clone the repository.
2. Navigate to the project directory.
3. Open `Index.html` in a web browser.
4. View the website locally.

## Usage

Open `Index.html` in a web browser to view the Keofi website. Explore the menu, learn about the café, and use the contact section to find location and hours.
